# Prolific 提交对账术语

本语境区分平台参与记录、本地标注结果和完成码，避免把不同来源的数量混为一谈。

## Language

**平台提交（Platform submission）**：一次研究参与记录，由 Submission ID 标识；在本研究入口中对应 Session ID。它的存在不证明已有本地标注答案。
_Avoid_: 不指明来源的“提交”

**本地标注结果（Local result）**：标注服务器保存的该次参与的最终答案。不同于草稿，也不同于平台待审核记录。

**待审核但无本地结果（AW without local result）**：平台状态为 AWAITING REVIEW，但对应研究、session 和参与者的最终答案尚未在本地找到的对账差异。
_Avoid_: NOCODE 人群、自动认定未做题

**完成码（Completion code）**：研究完成路径的标记，不是参与者或 session 的唯一标识。

**NOCODE**：参与者未提供正常完成码而在平台完成提交时使用的完成码标记，不是提交状态，也不证明答案缺失。

**Unknown code**：参与者提供了该研究未识别的完成码；同样不证明答案缺失。

**RETURNED**：平台提交已退回的状态，可出现在研究进行中或完成后；它本身不说明退回原因。

**退回请求（Return request）**：请求参与者退回其平台提交的消息，不等于已发生 RETURNED。

**撤回数据使用同意**：参与者撤回对研究使用其数据的同意；不能仅从 RETURNED 状态推断。

**正式计数**：用于决定 sample 是否还需要收集标注的结果计数，不等于平台待审核数。

**临时占位**：任务已分配但尚无最终答案时对可用标注名额的占用。
