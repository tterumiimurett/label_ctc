# 06: 安全发送退回请求并记录结果

**Status:** Approved draft — pending tracker publication

**Publication label:** ready-for-agent

**Blocked by:** 05 — 确认缺失后生成唯一待联系请求。

**What to build:** 对获准候选发送一条退回请求，并可判断已发送、取消、失败或结果不确定。

- [ ] 发送前再次检查当前平台状态和最终答案，已到达答案或状态变化取消发送。
- [ ] 采用一种消息操作保留已确认文案，不同时发结构化请求和普通消息。
- [ ] 持久化发送状态，每session最多一次；发送超时先查证，不盲目重试。
- [ ] 不确定且无法查证转人工；发送成功不视为RETURNED，不改变审核/支付或立即释放名额。
- [ ] 隔离完整验证消息副作用；真实发送默认关闭，历史清单须批准。
